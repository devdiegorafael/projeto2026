# Projeto 2026 - Fundamentos de HTML e CSS

Este repositório contém meu portfólio de estudos em **HTML e CSS**.  
Cada conteúdo que aprendo vira uma página prática, com exemplos e explicações.

## 🚀 Acesso ao projeto
- Repositório no GitHub: [projeto2026](https://github.com/devdiegorafael/projeto2026)
- Site publicado: [Portfólio Online](https://devdiegorafael.github.io/projeto2026)

## 📂 Estrutura do projeto
- `index.html` → Página inicial com menu e cards.
- `classe-ids.html` → Explicação sobre Classes e IDs.
- `cabecalhos.html` → Uso das tags de cabeçalhos (h1 ao h6).
- `div-span.html` → Diferença entre Div e Span.
- `paragrafos.html` → Parágrafos e linhas horizontais.
- `formatacao.html` → Tags de formatação de texto.
- `css/style.css` → Estilos globais do site.

## 🎨 Tecnologias usadas
- HTML5
- CSS3
- Git & GitHub (versionamento e publicação)

## 📌 Objetivo
Este projeto serve como portfólio de aprendizado, mostrando minha evolução nos estudos de desenvolvimento web.
