Classes e IDs em HTML

O que são Classes?

As classes são usadas para aplicar estilos em vários elementos ao mesmo tempo. Pense nelas como etiquetas que você pode colar em diferentes partes da página para dar a mesma aparência.

Exemplo:

<p class="destaque">Este é um parágrafo destacado.</p>
<p class="destaque">Outro parágrafo com o mesmo estilo.</p>

Resultado: dois parágrafos diferentes, mas ambos recebem o mesmo estilo definido pela classe .destaque.

O que são IDs?

Os IDs identificam um único elemento na página. Cada ID deve ser único e não pode se repetir. É como dar um “nome exclusivo” para um elemento.

Exemplo:

<p id="principal">Este é o parágrafo principal.</p>

Resultado: apenas esse parágrafo pode ser estilizado usando #principal no CSS.

Diferença entre Classes e IDs

  • Classes: podem ser usadas em vários elementos.
  • IDs: devem ser únicos, usados em apenas um elemento.

Dica: use classes para estilos repetidos e IDs para elementos únicos, como cabeçalhos ou seções específicas.
